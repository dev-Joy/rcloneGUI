## 문제

개발 명령(`pnpm run dev`) 없이 앱을 설치해 쓰고, 로그인할 때 자동으로 켜고 싶다.

## 바라는 결과

- `pnpm run dist`로 Windows 설치 파일(NSIS, 사용자 단위).
- 설정의 "로그인할 때 시작"(기본 끔).

## 영향

- `electron-builder.yml`, 설정 `launchAtLogin`, IPC `app:info`, 설정 창.

## 제약

- 설치본에는 `out/`과 운영 의존성만(소스 · 테스트 · 문서 · 하네스 제외).
- PC를 바꾸는 일(설치 · 자동 시작)은 사용자 승인 뒤에만 시험한다.

## 결정된 것

- NSIS 사용자 단위, 자동 시작 기본 끔, 코드 서명 없음 — 사용자 "진행".

## 계획 (한 것)

1. electron-builder 추가(THIRD_PARTY_NOTICES)
2. 실제 등록 값은 `executableWillLaunchAtLogin`으로 읽기

## 결과

- R2 통과(R1 reviewer: 작업 관리자에서 끈 것이 안 보이고 다른 설정 저장 때 다시 켬 → 체크를 바꿔 저장할 때만 반영).
- 확인 못 함: Setup.exe 설치 · 제거, 자동 시작 실제 등록 — 사용자 승인 대기(009).
