# 007 작업 화면 단추 묶음 정리

- 작성: Claude (사용자 지적 2026-10-22) · 상태: 계획
- 관련: 작업 화면(`JobPage`) 도구 줄

## 문제

작업 화면 위 한 줄에 성격이 다른 것이 섞여 있다: **할 일**([비교] [동기화] [중지]), **도구**([미리보기 명령 복사] [실행 명령 복사]), **보기 바꾸기**([비교 결과] [실행 기록] 탭). 사용자는 "성격이 다른 게 같이 묶여 있으니 헷갈린다"고 했다.

## 바라는 결과

```
작업 이름                                  [편집] [복제] [삭제] [⋯]
원본 → 대상
─────────────────────────────────────────────────────────────
[비교]  [동기화: 대상에 3개 복사, 1개 삭제]  [중지]
─────────────────────────────────────────────────────────────
 파일 목록 │ 기록                         ← 탭 (아래 내용만 바꿈)
 (상태별 칩 · 보기 · 트리/평면)
 파일 목록 …
```

- **할 일 줄**: [비교] [동기화] [중지]만. 가장 눈에 띄게.
- **탭**(파일 목록 · 기록. 구현 R3에서 이름을 내용에 맞춤)은 할 일 줄 아래, 목록 바로 위에 붙여 "아래 내용을 바꾸는 것"임이 보이게(탭 모양 · 밑줄).
- **명령 복사**는 작업 이름 줄의 [⋯] 메뉴로: "비교 명령 복사", "동기화 명령 복사"(006 용어). 자주 쓰지 않는 도구이므로.

## 영향

- 화면만: `JobPage.tsx` · `.module.css`, 작은 메뉴(F23의 `ItemMenu` 재사용 가능). 실행 · 안전장치와 무관.

## 제약

- [동기화] 단추를 켜고 끄는 조건은 그대로(`usablePreview`, 안전장치).
- 좁은 창(886)에서 할 일 줄 · 탭이 잘리지 않을 것.

2. 탭을 목록 위 따로 줄로 옮기고 탭 모양 CSS.
3. 006과 함께 문구 정리.
4. 증명: app-verifier — 단추 위치 · 탭 전환 · 메뉴 복사 · 886px · 키보드(Tab 순서, 메뉴 키).
