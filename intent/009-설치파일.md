- 관련: F12(설치본, R2 통과)

## 문제

`dist/rcloneGUI-Setup-0.1.0.exe`는 F12 검증 때 만든 것이라 그 뒤 기능(F20 ~ F27, 목록 · 스냅샷 등)이 없다.

## 바라는 결과

- 위 계획(001 ~ 008)이 끝난 뒤 `pnpm run dist`로 새 설치 파일을 만들고, 버전을 올린다(0.1.0 → 0.3.0, `package.json` · CHANGELOG 제목).
- 만든 파일의 이름 · 크기 · 위치를 알린다.

## 제약

- 설치 · Windows 로그인 시 자동 시작 시험은 PC를 바꾸므로 **사용자 승인 뒤에만**.
- 코드 서명이 없어 SmartScreen 경고가 뜰 수 있다고 알린다.

## 미해결 질문 (사람이 정함)

- [ ] 설치까지 해 볼지, 자동 시작 시험까지 할지.

## 계획

1. 버전 올리기, CHANGELOG 정리(0.3.0).
2. `pnpm run check` · `test:int` · `pnpm run dist`.
3. 설치 시험은 승인 뒤: 설치 → 실행 → 작업 하나 비교 → 제거.
