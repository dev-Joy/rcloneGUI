# 027 Google Drive 실사용 확인과 수정

- 작성: Claude (사후 작성 2026-10-23 — 이미 만든 기능을 TASK_028 · TASK_030 기록로 정리) · 상태: 완료

## 문제

Google Drive 리모트로 실제로 돌려 보니 처음 보는 대상 폴더 · 앱 종료 · 웹 주소 입력에서 문제가 드러났다.

## 바라는 결과

- 리모트 대상 폴더가 아직 없어도 첫 비교가 된다(lsjson exit 3을 빈 목록으로).
- 실행 도중 앱이 꺼지면 그 기록을 다음에 켤 때 실패로 닫고, 앱이 끝날 때 rclone도 멈춘다.
- 경로 칸에 Drive 웹 주소를 넣으면 저장할 때 막고, "설정에 없는 리모트" 오류를 알기 쉽게 알린다(critical 줄도 오류로 모음).

## 영향

- `runner`, `clsRunStore.closeInterrupted`, `validateJobPaths`, `describeExit`.

## 제약

- 사용자의 실제 리모트 · 프로필은 검증에서 건드리지 않는다(테스트는 환경 변수 local 리모트로 재현).
- 웹 주소 확인은 저장 때만 — 예전에 저장된 작업 목록은 계속 열린다.

## 결정된 것

- 사용자 지적(".claude · AGENTS.md 참고하는 거 아니었어?")으로 수정도 검증 루프에 올림.

## 계획 (한 것)

1. 고치기 전 실패하는 통합 테스트
2. 새 Drive 폴더(하위 폴더)로 비교 → 동기화 → 삭제 확인 → 백업 확인

## 결과

- R3 통과. 새 Drive 폴더에서 비교 · 동기화 · 백업(`.rclonegui-backup/drive/<실행>`) · 재비교 "바뀔 것 없음" 확인.
- 남은 것: 중단된 실행이 남긴 *.partial이 다음 비교에서 삭제 대상으로 보임, fast-list 미확인.
