# 003 리모트 등록 · 리모트 폴더 고르기

- 작성: Claude (사용자 메모 2026-10-22를 정리) · 상태: 계획 (ADR 필요)
- 관련: F15(리모트 추가 화면, v0.4), 2026-10-17 Drive 폴더 주소 붙여 넣기(TASK_031)

## 문제

리모트(Google Drive 등)를 쓰려면 터미널에서 `rclone config create …`를 쳐야 하고, 대상 칸에는 리모트 경로(`gdrive-test:백업`)를 손으로 써야 한다. 리모트 안의 폴더를 눈으로 보고 고를 수 없다.
사용자 요구: "작업 추가 · 편집 시 리모트 등록 기능. 등록된 리모트를 선택 후 해당 리모트 폴더를 선택할 수 있는 기능".

## 바라는 결과

- 편집 창 원본 · 대상 칸 옆 **[리모트 폴더]** 단추 → 대화상자: 왼쪽에 등록된 리모트 목록(이름 · 종류), 오른쪽에 고른 리모트의 폴더 트리(펼칠 때마다 한 단계씩 읽음). 폴더를 고르면 칸에 `리모트:경로`가 들어간다. 새 폴더 이름을 끝에 붙일 수 있다.
- 같은 대화상자에 **[새 리모트]**: 이름과 종류(우선 Google Drive)를 고르고 [브라우저에서 로그인] → rclone이 브라우저를 열어 Google 로그인 · 허용 → 끝나면 목록에 나타난다. 선택: Drive 폴더 주소를 넣으면 그 폴더를 맨 위로(`root_folder_id`). 선택: 자기 GCP `client_id` · `client_secret`(입력 칸은 가림 처리, 기록 · 로그에 남기지 않음).

## 영향

- main: `rclone lsjson <리모트>:<경로> --dirs-only`(읽기 전용) 폴더 읽기, `rclone config create`(rclone이 rclone.conf에 씀) 실행. 새 IPC: `remotes:dirs`, `remotes:create`, `remotes:create-cancel`.
- 화면: `RemoteBrowserDialog`(새), 편집 창.

## 제약 (안전 규칙과의 관계)

- AGENTS.md 1.6 "rclone.conf는 경로로만 넘긴다. 앱 코드에서 열어 읽거나 기록에 남기지 않는다": 앱은 계속 열지 않는다. 리모트 만들기는 **rclone이** 쓰고, 앱은 결과를 `listremotes`로만 확인한다. 그래도 앱이 rclone.conf를 **바꾸는 첫 기능**이므로 **ADR**로 남긴다(무엇을 · 언제 · 어떤 인자로 쓰는지, 덮어쓰기 금지: 같은 이름이 있으면 만들지 않음).
- client_secret 같은 값은 rclone 인자로만 넘기고 기록(실행 명령 기록 · 로그 · DB)에 남기지 않는다. 명령 미리보기 문구에서도 가린다.
- 폴더 읽기는 `lsjson --dirs-only --max-depth 1`(읽기 전용, `assertSafeArgs`).
- OAuth는 rclone이 띄우는 로컬 웹 서버 + 브라우저. 앱은 로그인 정보를 보지 않는다. 5분 안에 끝나지 않으면 취소.

## 미해결 질문 (사람이 정함)

- [ ] 첫 판에서 지원할 종류: Google Drive만(제안) / OneDrive · S3 · SFTP도.

## 계획

1. (승인 불필요) 리모트 폴더 고르기: `remotes:dirs {remote, path}`(경로 검사: 리모트 이름은 listremotes 결과에 있는 것만), `RemoteBrowserDialog` 트리, 편집 창 단추. 테스트: 인자 · 검사 단위, 통합(환경 변수 local 리모트로 폴더 읽기).
2. (ADR 승인 뒤) 리모트 만들기: ADR 0007, `remotes:create {name, type: "drive", rootFolderId?, clientId?, clientSecret?}` → `rclone config create <name> drive scope=drive …` (shell false, 이름 중복이면 거부), 진행 상태 · 취소, 완료 뒤 목록 새로 읽기. 비밀값 가림 테스트.
3. 증명: `pnpm run check`, `test:int`(local 리모트), app-verifier(폴더 트리 · 고르기, 리모트 만들기는 실제 OAuth 대신 취소 흐름과 이름 중복 거부까지), 실제 Drive 로그인은 사용자 PC에서 사용자와 함께 확인.
