# 011 비교 · 동기화 · 안전장치

- 작성: Claude (사후 작성 2026-10-23 — 이미 만든 기능을 TASK_001 기록로 정리) · 상태: 완료
- 만든 날: 2026-10-11 · 관련: PRD F04 · F05 · F06, SR-01 ~ SR-09, ADR 0002 · 0003 · 커밋 2527c98 · 82ed703

## 문제

rclone sync는 원본에 없는 파일을 대상에서 지운다. 무엇이 지워질지 보지 않고 돌리면 되돌리기 어렵다.

## 바라는 결과

- [비교]: `--dry-run --combined` 결과를 추가 · 변경 · 삭제 · 같음 · 오류로 나눠 3열 목록과 요약으로 본다.
- [동기화]: 비교를 확인한 뒤에만 실행하고, JSON 로그로 진행률을 보이며, 중지할 수 있다.
- 실제 동기화는 "비교 → 사람이 확인 → 확인한 만큼만 삭제 허용" 순서로만 일어난다.

## 영향

- `clsRcloneRunner.preview()` · `execute()`, `command-builder` 차단 목록, 화면 비교 목록 · 확인 창.

## 제약

- SR-01 비교 필수(성공한 최신 비교 30분 안, 설정이 바뀌면 무효), SR-02 삭제 확인 체크, SR-03 `--max-delete` 고정, SR-04 백업 기본 켬, SR-05 `--ignore-errors` 기본 없음, SR-06 빈 · 없는 원본 차단, SR-07 경로 겹침 거부, SR-08 대상당 동시 1개, SR-09 위험 옵션 차단.
- `--dry-run` 없는 실행은 `execute()` 한 곳에서만.

## 결정된 것

- 비교는 `--dry-run --combined` — ADR 0002.
- `--ignore-errors`는 기본으로 끄고 백업이 켜진 작업에서만 — ADR 0003(뒤에 004에서 A안으로 다시 확인).

## 계획 (한 것)

1. `buildArgs`와 차단 목록 단위 테스트
2. 실행기 검사(비교 없이 · 확인 수 다름 · 30분 · 설정 바뀜)를 통합 테스트로
3. 확인 창 체크 전에는 실행 단추 꺼짐
