# 018 동기화 범위 (파일만 · 전체 · 폴더 구조만)

- 작성: Claude (사후 작성 2026-10-23 — 이미 만든 기능을 TASK_018 기록 · 명세로 정리) · 상태: 완료
- 만든 날: 2026-10-16 · 관련: PRD F25, SR-06, ADR 0006, 명세 [`docs/specs/2026-10-14-sync-scope.md`](../docs/specs/2026-10-14-sync-scope.md) · 커밋 2301269

## 문제

빈 폴더를 만들지 · 폴더 구조만 맞출지 고를 수 없었고, 실험해 보니 sync는 대상에만 있는 빈 폴더를 지우는데 combined에 나오지 않아 비교에 안 보였다.

## 바라는 결과

- 작업 옵션 범위: 파일만(기본) · 전체(빈 폴더까지) · 폴더 구조만.
- 폴더 작업도 비교 · 확인 창 · 결과에 보인다.

## 영향

- `buildArgs`(`--create-empty-src-dirs`, 필터 `+ */` · `- *`), JSON 로그 폴더 작업 파서, 목록 · 트리 · 확인 창.

## 제약

- 비교와 동기화에 같은 인자를 쓴다.
- 삭제 수 · `--max-delete`는 파일 기준.

## 결정된 것

- "폴더 구조만"에서만 SR-06 파일 수 검사를 하지 않는다 — 사용자 확인(2026-10-16), ADR 0006.

## 계획 (한 것)

1. 실험 P1 ~ P6 · fixture
2. 파서 · 빌더 · 트리 테스트, 통합(빈 폴더 삭제 표시 · 폴더 구조만은 파일 불변)

## 결과

- R2 통과(R1 reviewer: 필터에 걸린 파일만 든 폴더를 "지움"이라 했지만 실제로는 남음 → "비어 있으면 지움" · 실행 뒤 실제 확인).
- 남은 것: 그런 폴더가 있으면 비교마다 [동기화]가 켜짐.
