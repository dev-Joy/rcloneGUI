# 001 작업 목록에 원본 · 대상 표시

- 작성: Claude (사용자 메모 2026-10-22를 정리) · 상태: 계획
- 관련: PRD "작업 목록 (변경)", TASK_033(최근 동기화 · 주기 · 다음 실행은 이미 있음)

## 문제

왼쪽 작업 목록은 이름 · 최근 실행 · 자동 실행(주기 · 다음 시각)만 보인다. 작업이 늘면 **어느 폴더를 어디로** 맞추는 작업인지 이름만으로 알기 어렵다.
사용자 요구: "왼쪽 작업에 원본, 대상 폴더, 자동화 여부, 자동화 시기".

## 바라는 결과

- 작업 한 줄에서 원본 → 대상을 짧게 볼 수 있다. 자동화 여부 · 시기(주기 · 다음 시각)는 지금처럼.
- 목록 폭(250px)에서 잘리지 않고 읽힌다: 경로는 **끝 폴더 이름 위주**로 줄인다(예: `…\프로젝트 → gdrive-test:백업`). 전체 경로는 툴팁.
- Drive 연결 문자열(`리모트,root_folder_id=…:`)은 "Drive 폴더(리모트)"처럼 읽기 쉽게.

## 영향

- 화면: `JobListPane`, 경로 줄이기 순수 함수(`src/lib`). main · 실행과 무관.

## 제약

- 실제 사용자 경로를 테스트에 넣지 않는다(임시 · 가짜 경로).

## 미해결 질문

- 없음(줄이는 규칙은 아래 계획대로 하고 사용자가 화면을 보고 바꾸자고 하면 고친다).

## 계획

1. `src/lib/path-text.ts` `shortPath(path)`: 로컬 `C:\a\b\c` → `…\b\c`(마지막 두 칸), UNC · WSL은 배포판 + 끝 폴더, 리모트 `name:a/b` → `name:…/b`, Drive 연결 문자열 → `Drive 폴더(name)` + 하위 경로.
2. `JobListPane`: 이름 아래 첫 줄을 "원본 → 대상", 둘째 줄을 최근 실행, 셋째 줄(자동일 때)을 자동 · 주기 · 다음으로. 줄 툴팁에 전체 경로 추가.
3. 테스트: `shortPath` 경우별(로컬 · 드라이브 루트 · UNC · WSL · 리모트 · Drive 연결 · 긴 이름).
4. 증명: `pnpm run check`, app-verifier가 886px · 긴 경로 · Drive 연결 작업에서 말줄임과 툴팁 확인.
