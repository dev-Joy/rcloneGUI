# 006 용어 점검

- 작성: Claude (사용자 지적 2026-10-22) · 상태: 계획 — **아래 표를 사용자가 확인**
- 관련: AGENTS.md "UI 문구는 일어날 일을 쓴다"

## 문제

화면 문구 일부가 AI가 만든 티가 나고 뜻을 알기 어렵다. 사용자 예: "기타: 상태 칩대로". 같은 것을 여러 이름으로 부르기도 한다(미리보기/비교, 리모트/연결, 실행/동기화).

## 원칙

1. **같은 것은 한 이름**: 사용자가 누르는 단추 이름을 기준으로 통일한다 — "비교"(= dry-run 미리보기), "동기화"(= 실제 실행). 화면에서 "미리보기"라는 말은 쓰지 않는다.
2. **개발 용어 대신 보이는 말**: 칩 · 체인 · 스냅샷 · 리모트처럼 낯선 말은 풀어 쓰거나 설명을 붙인다. 단 rclone 공식 용어(리모트, rclone.conf)는 그대로 두고 처음 나올 때 괄호 설명.
3. **짧게, 일어날 일로**.
