# F28 옵션값 글자 수 제한

- 날짜: 2026-10-14
- 요구사항: [prd.md](../prd.md) F28 (P1, v0.2)

## 목적

작업 편집 · 설정 창의 입력값에 최대 글자 수를 둔다. 같은 숫자를 main의 zod 스키마(IPC 검증)와 화면 입력창(`maxLength`)이 함께 써서,
화면에서 막힌 값과 main이 거부하는 값이 어긋나지 않게 한다. 넘친 경우의 안내를 한국어로, 어느 칸인지 알 수 있게 쓴다.

## 지금 상태

`src/shared/schemas.ts`에 이미 상한이 있다(이름 100, 경로 1024, 제외 패턴 한 줄 512 · 200줄). 다만:

- 화면 입력창에는 상한이 없어 저장을 눌러야 알게 된다.
- 넘쳤을 때 zod 기본 메시지(영어, 칸 이름 없음)가 그대로 보인다.
- 제외 패턴 칸은 줄 수와 줄 길이를 저장 전에 알려주지 않는다.

## 동작

### 상한 (한 곳에 정의)

새 파일 `src/shared/limits.ts`에 `INPUT_LIMITS`를 둔다. 값은 지금 스키마와 같게 유지한다(이미 저장된 작업이 거부되지 않게).

| 키               | 값   | 쓰는 곳                                                               |
| ---------------- | ---- | --------------------------------------------------------------------- |
| `jobName`        | 100  | 작업 이름                                                             |
| `path`           | 1024 | 원본 · 대상 · 작업 전용 rclone.conf · 설정의 rclone.exe · rclone.conf |
| `excludePattern` | 512  | 제외 패턴 한 줄                                                       |
| `excludeCount`   | 200  | 제외 패턴 줄 수                                                       |

### 스키마 메시지

- 이름: `이름은 100자까지 쓸 수 있습니다`
- 경로: `경로는 1024자까지 쓸 수 있습니다`
- 제외 패턴 한 줄: `제외 패턴 한 줄은 512자까지 쓸 수 있습니다`
- 제외 패턴 줄 수: `제외 패턴은 200줄까지 쓸 수 있습니다`

### 화면

- 이름 · 원본 · 대상 · 작업 전용 rclone.conf · 설정의 두 경로 입력에 `maxLength`를 건다. 붙여 넣은 값도 브라우저가 잘라 상한을 넘지 않는다.
- 제외 패턴 칸 아래 안내(`hint`)에 `N / 200줄`을 보여준다. 줄 수가 넘치거나 512자를 넘는 줄이 있으면 안내를 오류 문구로 바꾸고
  (`3번째 줄이 512자를 넘습니다`처럼 첫 번째 문제 줄), [저장]을 끈다.
- 숫자 칸(checkers · transfers)은 지금처럼 `min` · `max`(1 ~ 64)를 쓴다. 바꾸지 않는다.

## 안전

지우거나 덮어쓰는 경로는 생기지 않는다. 검증은 main(zod)이 최종이고, 화면 제한은 미리 알려주는 용도다.
화면을 우회한 IPC 호출도 main에서 같은 상한으로 거부된다.

## 바꿀 파일

| 파일                            | 변경                                                     |
| ------------------------------- | -------------------------------------------------------- |
| `src/shared/limits.ts` (새)     | `INPUT_LIMITS`                                           |
| `src/shared/schemas.ts`         | 상한을 `INPUT_LIMITS`로, 한국어 메시지                   |
| `src/pages/JobEditorDialog.tsx` | `maxLength`, 제외 패턴 줄 수 · 줄 길이 안내, [저장] 조건 |
| `src/pages/SettingsDialog.tsx`  | `maxLength`                                              |
| `tests/unit/job-store.test.ts`  | 상한 경계(정확히 상한은 통과, 하나 넘으면 거부)와 메시지 |

새 IPC 채널은 없다.

## 확인 방법

1. `pnpm run check`
2. 화면: 이름 칸에 101자를 붙여 넣으면 100자로 잘린다. 제외 패턴에 201줄을 넣으면 안내가 오류로 바뀌고 [저장]이 꺼진다. 줄을 지우면 다시 켜진다.

## 하지 않는 것

- 상한 값을 바꾸는 일 (필요하면 별도 요청)
- 글자 수 대신 바이트 수 제한
