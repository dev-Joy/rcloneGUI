# F19 비교 트리 보기

- 날짜: 2026-10-14
- 요구사항: [prd.md](../prd.md) F19 (P1, v0.2). 데이터는 F11(파일 상세)을 쓴다.

## 목적

비교 결과를 폴더 트리로 본다. 폴더를 접고 펼 수 있고, 폴더 줄에서 그 아래에 일어날 일의 건수와 크기 합계를 바로 본다.
파일이 많은 프로젝트에서 "어느 폴더에서 무엇이 바뀌는지"를 먼저 보고 들어갈 수 있게 한다.

## 결정 (사용자 확인 2026-10-14)

- 기본은 트리, 목록 위의 [트리 | 평면] 전환으로 지금의 평면 목록도 남긴다.
- 트리 표는 공용 컴포넌트 `ZBCTreeTable`로 만든다(가상 스크롤). F21 작업 그룹 트리에서도 다시 쓴다.

## 동작

### 트리 만들기 (`src/lib/file-tree.ts`, 순수 함수)

- `buildFileTree(items)`: combined 항목의 경로(`/` 구분)로 폴더 노드를 만든다. combined에는 파일만 나오므로 폴더는 경로에서 만든다.
- 폴더 노드의 집계(그 아래 모든 파일, 화면 필터 적용 후):
    - 상태별 건수(`add` · `change` · `delete` · `same` · `error`)
    - 원본 크기 합, 대상 크기 합(상세가 있는 파일만. 상세가 없으면 비움)
    - "대상이 더 최신"(`isDestNewer`) 파일 수
- 정렬: 같은 폴더 안에서 폴더 먼저, 그다음 파일, 각각 이름 순. 실행 환경 로캘과 무관하게 고정한 비교(영문 → 한글, 숫자는 크기 순 `a2 < a10`).
- `flattenTree(root, collapsed)`: 펼친 폴더만 따라가 화면에 그릴 줄 목록(깊이, 폴더 여부, 펼침 여부)을 만든다.
- 필터(상태 칩)를 적용한 뒤 트리를 만든다. 보이는 파일이 하나도 없는 폴더는 나오지 않는다.

### 공용 컴포넌트 `ZBCTreeTable`

- 위치 `src/components/ZBCTreeTable.tsx` + `ZBCTreeTable.css`(`ZBC.css`에서 import). className `zbc zbcTreeTable`, 내부는 `zbcTreeTable*`.
- props: `rows`(평탄화된 줄: `id`, `depth`, `hasChildren`, `expanded`), `columns`(머리글 · 너비 · 칸 그리기 함수), `onToggle(id)`, `rowHeight`, `emptyText`.
- 첫 열에 깊이만큼 들여쓰기와 펼침 단추(▸ / ▾). 단추는 `button`이라 키보드로도 누를 수 있다. 줄 전체 더블클릭으로도 접고 편다.
- `@tanstack/react-virtual`로 보이는 줄만 그린다(지금의 평면 목록과 같은 방식).
- 도메인(파일 · rclone)을 모른다. 칸 내용은 쓰는 쪽이 그린다.

### 비교 화면

- 열: 항목 · 원본 크기 · 원본 수정 시각 · 일어날 일 · 대상 수정 시각 · 대상 크기.
  (GoodSync의 "상태" 열은 두지 않는다. "일어날 일"이 그 역할이다.)
- 파일 줄: 지금 평면 목록과 같은 배지와 "대상이 더 최신" 표시, 없는 쪽은 "없음".
- 폴더 줄: 이름(굵게), 크기 열에 합계, 일어날 일 열에 건수 요약(예: `복사 3 · 덮어씀 1 · 삭제 2`, 0인 것은 빼고 copy · sync에 맞는 말은 `chipName`), "대상이 더 최신"이 있으면 그 수.
- 처음에는 모두 펼친다. 모두 펼친 줄이 5,000개를 넘으면 폴더를 모두 접어 맨 위 단계만 보이게 시작한다(첫 화면이 너무 길어지지 않게).
- [모두 펼치기] [모두 접기] 단추.
- [트리 | 평면] 전환. 고른 보기와 접힘 상태는 작업별로 화면 상태에만 둔다(앱을 다시 켜면 트리, 모두 펼침).
- 실행 기록에서 지난 실행을 열어도 같은 트리로 본다.

## 안전

화면 표시만 바뀐다. 실행 조건, IPC, main은 바뀌지 않는다. 지우거나 덮어쓰는 경로는 생기지 않는다.

## 확인 방법

1. `pnpm run check`
2. 화면: 하위 폴더가 있는 원본으로 비교 → 트리로 보이고 폴더 줄에 건수 · 크기 합 → 폴더 접기 · 펴기(단추, 더블클릭, 키보드) → 상태 칩을 바꾸면 트리와 폴더 건수가 따라 바뀜 → [평면]으로 바꾸면 지금 목록 → [동기화] 흐름은 그대로.
3. 파일 2만 개 이상에서 스크롤이 끊기지 않고, 처음에는 폴더가 접혀 맨 위 단계만 보인다.

- 열 너비 조절 · 정렬 바꾸기
- 접힘 상태 저장
