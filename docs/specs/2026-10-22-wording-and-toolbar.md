# 화면 용어 통일 · 작업 화면 단추 정리

- 날짜: 2026-10-22
- 의도: [intent/006 용어 점검](../../intent/006-용어-점검.md), [intent/007 작업 화면 단추 정리](../../intent/007-작업화면-단추-정리.md), [intent/004](../../intent/004-ignore-errors-단독.md) A안(문구만)
- 사용자 "진행해 확인했어"(2026-10-22): 용어표 확인, 004는 A(안전장치 그대로)

## 목적

뜻을 알기 어렵거나 어색한 문구(예: "기타: 상태 칩대로")를 고치고, 같은 것을 한 이름으로 부른다("비교" = dry-run, "동기화" = 실제 실행. 화면에서 "미리보기"를 쓰지 않는다).
작업 화면 위 한 줄에 섞여 있던 할 일 · 도구 · 보기 바꾸기를 나눈다.

## 동작

- 문구: intent/006 용어표대로. 표 밖에서 함께 고친 것: 동기화 확인 창 제목 "실행 확인" → "동기화 확인", "실행하면 공간이 모자라" → "동기화하면 …", 편집 창 copy 설명 "그대로 둠" → "지우지 않음", 목록 보기 사유("성공한 비교 결과에서만", "이전 동기화가 없음", "동기화 기록에서만", "동기화가 끝난 뒤"), 처리 못 한 파일 표시 "· 처리 못 함", 제외 표시 "제외 패턴에 걸림 · 건드리지 않음".
- `--ignore-errors` 체크 문구 · 경고(004 A): 왜 백업을 켠 작업에서만 허용하는지 쓴다. 안전장치는 바뀌지 않는다.
- 작업 화면:
    - 이름 줄: [편집] [복제] [삭제] [⋯]. [⋯] 메뉴에 "비교 명령 복사" · "동기화 명령 복사".
    - 할 일 줄: [비교] [동기화: …] [중지]만.
    - 그 아래(안내 띠 · 진행 배너 뒤) 밑줄 탭 "파일 목록 | 기록"(R3: 처음엔 "비교 결과 | 동기화 기록"이었으나 첫 탭에 동기화 결과도, 둘째 탭에 비교 기록도 나와 이름을 내용에 맞춤. 무엇을 보고 있는지는 아래 상태 줄 "비교 …" / "동기화 …")(`role="tablist"`, `aria-selected`).
- 파일 목록 가운데 열 이름: 비교는 "할 일", 동기화 기록은 "한 일".
- 옛 문구가 다시 들어오지 않게 단위 테스트(`tests/unit/wording.test.ts`)가 화면 코드(src/pages · src/lib)를 검사한다.

## 안전

- 표시와 배치만 바뀐다. [동기화] 단추 조건(`usablePreview`) · 확인 창 체크 · 실행 경로는 그대로다.
