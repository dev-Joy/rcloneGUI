# 변경 기록

## 0.1.0 (작업 중)

- 작업 등록·편집·복제·삭제 (원본, 대상, copy/sync, 제외 패턴, checkers/transfers)
- 비교: `rclone --dry-run --combined` 결과를 원본 · 일어날 일 · 대상 3열 목록과 상태 칩으로 표시
- 동기화: 미리보기 확인 뒤 실행, 진행률 표시, 중지
- 안전장치: 삭제 확인 창, 삭제 한도 고정, 백업 폴더 기본 켬, 빈·없는 원본 차단, 경로 겹침 검사
- 실행 기록: 실행별 결과·건수, 그때의 파일 목록, 로그·백업 폴더 열기
- 미리보기·실행 명령 복사
- 설정: rclone.exe와 rclone.conf 위치
- 저장: 작업 · 설정 · 실행 기록을 `rclonegui.db`(SQLite) 한 파일에 둠. 처음 켤 때 예전 `jobs.json` · `settings.json` · `run.json`을 가져오고 원본 파일은 남겨 둠. `jobs.json`이 깨져 있으면 오류 창을 띄우고 앱을 끝냄
- 입력 글자 수 제한: 이름 100자, 경로 1024자, 제외 패턴 한 줄 512자 · 200줄. 입력창이 넘치는 값을 받지 않고, 제외 패턴 칸 아래에 줄 수와 문제 줄을 보여 줌. 넘치면 [저장]이 꺼짐
- 설정: 새 작업의 기본 원본 · 대상 폴더. [+ 새 작업]의 칸을 채우고, 작업 편집의 [폴더 선택]이 그 위치에서 열림
- 비교: 원본 · 대상 크기와 수정 시각 표시(작업 옵션, 기본 켬). 대상이 원본보다 최신인데 덮어쓸 파일에 "대상이 더 최신" 경고, 실행 확인 창에 그 수와 목록
- 비교: 결과를 폴더 트리로 보기(기본). 폴더 줄에 그 아래 건수와 크기 합계, 접기 · 펴기, 모두 펼치기 · 접기, [트리 | 평면] 전환
- 동기화 범위: 작업마다 파일만(기본) · 전체(원본의 빈 폴더까지) · 폴더 구조만. 폴더 만들기와 대상에만 있는 폴더(비어 있으면 지움)를 비교 결과 · 확인 창에 표시하고, 실행 뒤에는 실제로 지운 빈 폴더와 남은 폴더를 나눠 표시 (sync가 대상의 빈 폴더를 지우는 것은 예전에도 일어났지만 보이지 않았음)
- 설치본: `pnpm run dist`로 Windows 설치 파일(사용자 단위, 코드 서명 없음). 설정에 "Windows에 로그인하면 rcloneGUI 시작"(기본 끔, 설치본에서만), 버전 표시
- 자동 실행(앱이 켜져 있는 동안): 작업마다 N분 간격 또는 cron 식. 먼저 비교하고 삭제가 자동 한도(기본 50) 이하일 때만 동기화. 비교 실패 · 읽기 오류 · 빈 원본 · 한도 초과 · 실행 실패면 실행하지 않고 그 작업의 자동 실행을 멈추고 Windows 알림, [다시 켜기]. 자동 실행 작업이 있으면 창을 닫아도 알림 영역에 남음. 실행 기록에 "자동" 표시. 앱 아이콘
- 체인 실행: 작업 편집에서 "이 작업이 성공하면 이어서" 작업을 고른다. 자동 실행이 성공하거나 바뀔 것이 없을 때만 뒤 작업을 같은 안전 흐름(뒤 작업의 자동 한도)으로 이어 돌리고, 앞이 실패 · 멈춤이면 돌지 않음. 수동 실행이 성공하면 [이어서: … 비교] 단추. 고리(A → B → A)는 저장 거부
- 화면: 안내 · 오류 알림을 위쪽에 띄워 대화상자 단추를 가리지 않게 하고, 오류도 10초 뒤 저절로 닫힘. 고르지 않은 작업도 목록에 마지막 실행 시각이 보임. rclone을 쓸 수 없으면 [이어서] 단추가 꺼짐
- 용량: 비교 뒤 원본 · 대상 드라이브의 여유 · 전체 용량과 옮길 크기를 작업 화면에 표시(rclone about). 대상 여유가 옮길 크기보다 작으면 경고(실행 확인 창에도)
- 작업 편집: 원본 · 대상 칸에 [WSL] 단추. 설치된 WSL 배포판의 맨 위 폴더(`\\wsl.localhost\배포판\`)에서 폴더 선택 창을 연다
- 진행 표시의 속도 · 남은 시간을 평균(보낸 양 ÷ 지난 시간)으로 계산. Drive가 큰 파일을 마무리하는 동안 "5.7 KB/s · 16시간"처럼 보이던 것을 고치고 "리모트가 파일 N개를 마무리하는 중"을 보여 줌
- 원본 · 대상 칸에 웹 주소(https://…)를 넣으면 저장 전에 "리모트 이름으로 쓰세요"로 막고, 설정에 없는 리모트로 실행하면 그 이름을 알려 줌
- 리모트 대상 폴더가 아직 없을 때(첫 실행)도 크기 · 수정 시각 · 제외됨을 읽음. 실행 도중 앱이 꺼진 기록은 다음에 켤 때 "앱이 꺼져 중단됨"으로 닫음. 앱을 끝내면 진행 중이던 비교 · 동기화(rclone)도 함께 멈춤(전에는 rclone이 남아 계속 돌 수 있었음)
- 항목별 동작: 일어날 일 칸에 방향 기호(→ · ✕ · = · !), 줄 오른쪽 클릭(또는 메뉴 키)으로 이번 실행에서 빼기 · 경로 복사. 빼면 다시 비교해야 동기화할 수 있고, 성공하면 다시 넣음
- 비교 결과 "기타" 보기: 포함됨 · 제외됨(필터에 걸린 파일, 요청할 때 읽음) · 새로 생김(지난 동기화 뒤) · 아직 실행되지 않음(실행 기록)
- 작업 그룹: 목록을 그룹별로 접고 펼쳐 봄, [+ 새 그룹] · 이름 바꾸기 · 지우기(작업은 그룹 없음으로 옮김), 편집 창에서 그룹 고르기
