# 0001 rclone은 실행마다 CLI 프로세스로 띄운다

- 상태: 채택 (2026-10-11)

## 배경

rclone을 붙이는 방법은 실행마다 `rclone sync …` 프로세스를 띄우는 것과, `rclone rcd`를 상주시켜 rc API로
작업을 넘기는 것 두 가지다.

## 결정

MVP는 실행마다 `spawn(rcloneExe, args[], { shell: false })`로 프로세스를 띄운다. 진행률은 stderr의 JSON 로그에서,
결과는 `--combined` 파일에서 읽는다.

## 버린 대안

- `rclone rcd` + rc API: 진행률과 작업 관리가 더 정교하지만 상주 프로세스 관리·인증·포트가 추가되고,
  앱이 만든 명령을 터미널에서 그대로 재현하기 어렵다.

## 결과

- 앱이 보여주는 명령을 복사해 앱 밖에서 같은 결과를 낼 수 있다.
- 취소는 프로세스 종료다. 중간 상태는 combined 기록과 백업 폴더로 확인한다.
- 파일 수가 아주 많아 진행률이 거칠게 느껴지면 rc API 전환(F16)을 다시 검토한다.
