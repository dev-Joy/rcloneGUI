# 0003 `--ignore-errors`는 기본 명령에서 뺀다

- 상태: 채택 (2026-10-11)

## 배경

지금까지 손으로 쓰던 두 명령에는 `--ignore-errors`가 있었다. rclone은 실행 중 오류가 하나라도 있으면
대상 파일을 지우지 않는데, 이 플래그는 그 보호를 끈다. v1.60.1 실험에서 원본 폴더 하나를 읽지 못하자
대상의 같은 폴더 파일이 지워졌다 (rclone-notes.md, 실험 E).

## 결정

- 생성하는 기본 명령에 `--ignore-errors`를 넣지 않는다.
- 작업의 고급 옵션 `safety.allowIgnoreErrors`로만 켤 수 있고, 백업 폴더가 켜진 작업에서만 허용한다.
  백업 없이 켜면 저장과 명령 생성이 모두 거부된다.

## 버린 대안

- 기존 명령과 똑같이 유지: 읽기 실패가 삭제로 바뀌고, 그 삭제가 다음 구간(Drive)까지 번진다.
- 완전히 금지: 소켓 파일 같은 사소한 오류 때문에 삭제가 계속 보류되는 작업을 풀 방법이 없어진다.

## 결과

- 원본에 읽기 오류가 있으면 삭제가 보류되고 실행은 실패로 기록된다. 사용자는 오류를 고치거나 해당 경로를 제외 패턴에 넣는다.
- 최신 버전에서 실험 E를 다시 확인하는 일이 남아 있다.
