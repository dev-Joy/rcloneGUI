# 0004 작업 정보는 rcloneGUI JSON에 두고 필터 파일로 넘긴다

- 상태: 일부 대체 (2026-10-14, 작업 저장 위치는 [0005](0005-sqlite-store.md))

## 배경

경로·제외 목록·옵션을 어디에 둘지 정해야 한다. rclone.conf의 `global.` 키로 옵션을 넣는 방법도 있다.

## 결정

- 작업은 `%APPDATA%\rcloneGUI\jobs.json`에 둔다. zod 스키마로 읽고 쓴다.
- 실행할 때 제외 패턴은 실행 폴더의 `filter.txt`(줄마다 `- 패턴`)로 써서 `--filter-from`으로, 나머지는 인자로 넘긴다.
- 리모트는 기존 rclone.conf를 `--config` 경로로만 참조한다. 앱은 그 파일을 열지 않는다.

## 버린 대안

- rclone.conf에 옵션까지 넣기: 토큰이 든 파일을 앱이 고쳐 써야 하고, 작업마다 다른 옵션을 표현하기 어렵다.
- 제외 패턴을 `--exclude` 인자 여러 개로: 동작은 같지만 실행 기록에 그때의 필터를 파일로 남기는 편이 재현하기 쉽다.

## 결과

- 실행 폴더에 `filter.txt`가 남아 그 실행을 그대로 재현할 수 있다.
- 포함 규칙(`+ 패턴`)은 아직 지원하지 않는다. 필요해지면 작업 스키마에 필터 줄을 그대로 받는 필드를 더한다.
